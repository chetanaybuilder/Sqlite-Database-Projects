# SQLite Database Projects

A collection of Python projects built using SQLite to explore database design, CRUD operations, and user authentication. This repository showcases practical database applications developed while learning Python and SQLite.

## Projects

### 🎓 Student Database
A simple student management system.

**Features**
- Add student records
- View student information
- Update records
- Delete records

---

### 🔐 User Registration System
A basic authentication system using SQLite.

**Features**
- User registration
- Login authentication
- Secure data storage

---

### 🤖 SQLite Chatbot
A chatbot integrated with SQLite for storing user data.

**Features**
- User authentication
- Chat history storage
- SQLite database integration

---
